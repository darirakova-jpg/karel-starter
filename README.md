# Karel Starter

This project is a Java programming project using Stanford Karel. Karel is a robot that follows simple commands such as moving, turning, picking up beepers, and placing beepers.

## What I Learned

Through this project, I learned how to:

- Use methods to give Karel instructions.
- Use commands such as `move()`, `turnLeft()`, `pickBeeper()`, and `putBeeper()`.
- Run a Java project using IntelliJ IDEA.
- Use Git and GitHub to store and manage my code.

## How to Run

1. Open the `karel-starter` folder in IntelliJ IDEA.
2. Make sure the Karel library in the `lib` folder is available to the project.
3. Open `MyKarel.java`.
4. Run the project using the provided `run.sh` script or the IntelliJ run configuration.
5. Karel will open in a window where the program can be tested.

## Project Structure

- `MyKarel.java` — the Java file containing my Karel program.
- `lib/` — contains the Karel library.
- `worlds/` — contains the Karel worlds used for the exercises.
- `run.sh` — script for running Karel on macOS.
- `run.ps1` — script for running Karel on Windows.
